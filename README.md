# ⚡ RocketscriptZ (Simple-Hub) - Complete Script Hub & Admin System

เว็บไซต์คลังแจกสคริปต์สไตล์ **RocketscriptZ** (โทนสีดำ-แดงนีออน Pure Black & Fiery Red) ที่ได้รับการอัปเกรดระบบครบวงจร เชื่อมต่อฐานข้อมูล SQLite ภายในตัว พร้อมระบบจัดการหลังบ้าน (Admin Panel) ที่สามารถ **"ปรับแต่งและแก้ไขได้ทุกส่วนของเว็บไซต์"**

---

## 🌐 ลิงก์เข้าใช้งานในเครื่อง

* **หน้าเว็บหลักสำหรับคนดู (Home):** [http://localhost:3005/](http://localhost:3005/)
* **ระบบจัดการหลังบ้าน (Admin Panel):** [http://localhost:3005/admin.html](http://localhost:3005/admin.html)

> 💡 **วิธีเปิดรันเซิร์ฟเวอร์:**
> รันคำสั่ง `npm run simple` หรือ `node simple-hub/server.js`

---

## 🛡️ ฟังก์ชันของระบบหลังบ้าน (admin.html) - แก้ไขได้ทุกอย่าง

### 1. 📋 จัดการสคริปต์ (Scripts Manager)
* **เพิ่มสคริปต์ใหม่:** กรอกข้อมูลเอง หรือใส่ Place ID / ลิงก์ Roblox เพื่อให้ระบบ **ดึงชื่อเกมและรูปภาพปกมาใส่ให้อัตโนมัติ (Auto Roblox Fetch)**
* **แก้ไขสคริปต์เดิม (Edit Anything):** สามารถแก้ไขได้ทุกฟิลด์ — ชื่อสคริปต์, ชื่อเกม, โค้ด Loadstring, ลิงก์รูปภาพ, ลิงก์วิดีโอ, แท็ก, สถานะ Keyless/Executor, รวมถึงยอดวิวและยอดไลก์
* **ลบสคริปต์:** ลบทีละตัว หรือเลือกหลายรายการเพื่อลบพร้อมกัน (Batch Delete)
* **ค้นหาและกรองสคริปต์:** ค้นหาแบบเรียลไทม์ในตารางหลังบ้าน

### 2. ⚙️ ตั้งค่าเว็บไซต์ & UI (Site & UI Customization)
* **ข้อมูลแบรนด์:** แก้ไขชื่อเว็บไซต์ (`siteTitle`), แฮนเดิล (`@siteHandle`), ลิงก์โลโก้
* **แถบประกาศด้านบนสุด (Top Announcement Bar):** ปรับแก้ข้อความประกาศ, ป้ายกำกับ, ลิงก์ Discord, ลิงก์ YouTube
* **หน้ารายละเอียดสคริปต์:** ปรับแก้ข้อความคำแนะนำสีแดง (Red Instruction Text), รูปภาพและลิงก์วิดีโอ Showcase

### 3. 🔒 ระบบปลดล็อค & Sub2Unlock
* **สวิตช์เปิด/ปิดการล็อคสคริปต์:** สลับให้ต้องทำภารกิจ หรือปลดล็อคทันทีทุกคน
* **สวิตช์เปิด/ปิดปุ่มข้ามทันที:** ซ่อนหรือแสดงปุ่ม Quick Bypass สำหรับทดสอบ
* **ปรับแต่งภารกิจ 3 ขั้นตอน:** แก้ไขข้อความปุ่ม และลิงก์ปลายทางของภารกิจที่ 1, 2, 3 ได้ตามต้องการ
* **เชื่อมต่อ LootLabs:** รองรับการเปิดใช้งาน LootLabs Gate เพื่อส่งผู้เล่นไปข้ามลิงก์ LootLabs ก่อนรับสคริปต์

### 4. ❓ จัดการคำถามที่พบบ่อย (Dynamic FAQ Manager)
* เพิ่มคำถาม-คำตอบใหม่ลงหน้าเว็บได้ทันที
* แก้ไขหรือลบคำถามที่มีอยู่เดิมได้ตลอดเวลา โดยไม่ต้องแตะต้องโค้ด

### 5. 🛡️ ความปลอดภัย & แบน IP (Security & Bans)
* ตรวจจับ IP และแสดงรายการ IP ที่เข้าใช้งาน
* สั่งแบน IP (ระบุระยะเวลา 24 ชม., 3 วัน, 7 วัน, 30 วัน หรือแบนถาวร พร้อมระบุเหตุผล)
* ปลดแบน IP ได้ทันที
* แสดงหน้าจอระงับการใช้งานอัตโนมัติหากผู้ใช้งานติดแบน

### 6. 💾 ฐานข้อมูล & สำรองข้อมูล (Database & Backup)
* แสดงสถิติจำนวนสคริปต์รวม, ยอดเข้าชมรวม, ยอดไลก์รวม, จำนวน IP ที่ถูกแบน
* **Backup JSON:** ดาวน์โหลดไฟล์สำรองข้อมูลสคริปต์และการตั้งค่าทั้งหมดเก็บไว้ในเครื่อง
* **Restore JSON:** อัปโหลดไฟล์สำรองข้อมูลเพื่อกู้คืนสคริปต์และคอนฟิกได้ทันที
* **Reset Default:** รีเซ็ตข้อมูลกลับเป็นสคริปต์เริ่มต้น
* **Clear All:** ล้างข้อมูลสคริปต์ทั้งหมดในระบบ

## 📁 โครงสร้างไฟล์ใน simple-hub/

```
simple-hub/
├── index.html       # หน้าเว็บหลัก (แสดงสคริปต์, ปลดล็อค Sub2Unlock, FAQ)
├── admin.html       # ระบบจัดการหลังบ้าน (แก้ได้ทุกอย่าง)
├── admin.js         # ลอจิกการทำงานของระบบจัดการหลังบ้าน
├── app.js           # ลอจิกหน้าเว็บหลัก เชื่อมต่อ REST API
├── server.js        # เซิร์ฟเวอร์ Node.js REST API + Static Server (Port 3005)
├── db.js            # ฐานข้อมูล SQLite (node:sqlite)
├── style.css        # สไตล์ธีมดำ-แดงนีออน (RocketscriptZ)
└── data/
    └── database.sqlite # ไฟล์ฐานข้อมูล SQLite
```
